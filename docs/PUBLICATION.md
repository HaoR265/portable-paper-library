# 首次公开发布检查

公开版从空库启动。采用文件白名单制作发布副本，并重新建立 Git 历史。

保留：应用源码、启动脚本、通用双语词表、虚构数据测试、说明及 MIT 许可证。

排除：私人数据库与目录导出、真实论文文件及译稿、纸本照片、下载清单、备份、日志、运行环境二进制、原始项目历史与个人绝对路径。原项目的固定编号导入函数和论文关系也已移除。

发布前对待提交文件检查了个人路径标识、真实目录标题、常见访问令牌和私钥标记。提交使用 GitHub noreply 邮箱。此检查针对首次发布副本，不保证使用者以后手工提交的文件自动脱敏。

本地回归通过四组测试：空库与检索打印状态、查重与附件分组移动、带哈希清单的完整备份恢复、HTTP 文件访问和写入限制。持续集成配置覆盖 Linux 与 Windows 的 Python 3.9 / 3.13；实时结果见 Actions。

首发仅提供源码包，需要 Python 3.9+，不包含真实论文或演示 PDF。Windows 10 尚未实测。
